# نظام إدارة مخازن قطع الغيار — النسخة الأولى

## ما الذي تحتويه النسخة؟
- ثلاثة مخازن مستقلة بأرصدة منفصلة.
- أصناف ببيانات الكود والاسم والتصنيف والموديل والوحدة وحد إعادة الطلب والأسعار ومكان الرف.
- تسجيل الإضافة والصرف مع منع الصرف بما يتجاوز الرصيد.
- تحويل داخلي بين المخازن مع خصم وإضافة متزامنين.
- لوحة رئيسية وتقرير نواقص وسجل آخر 300 حركة.
- تسجيل دخول وجلسات مستخدمين وصلاحيتان: مدير وموظف.
- سجل تدقيق لتسجيل الدخول والإجراءات الأساسية.

## التشغيل المحلي أو على سيرفر Linux/Windows مع Docker
1. ثبّت Docker Desktop (ويندوز) أو Docker Engine (Linux).
2. انسخ `.env.example` إلى `.env`.
3. غيّر `DB_PASSWORD` و`SECRET_KEY` و`ADMIN_PASSWORD` إلى قيم قوية وفريدة.
4. شغّل من مجلد المشروع:
   `docker compose up -d --build`
5. افتح `http://localhost:8000`.
6. سجّل الدخول باسم المستخدم وكلمة المرور المحددين في `.env`.

## تشغيله من أماكن مختلفة
هذه النسخة تحتاج إلى نشرها على خادم سحابي أو VPS بعنوان عام. لا تفتح المنفذ 8000 مباشرة على الإنترنت.
- اربط نطاقاً بالخادم.
- ضع Reverse Proxy مثل Caddy أو Nginx أمام التطبيق.
- فعّل HTTPS بشهادة TLS.
- اجعل قاعدة البيانات غير مكشوفة للإنترنت (هي داخل شبكة Docker فقط).
- استخدم كلمة مرور قوية وسرّاً عشوائياً، وفعّل نسخاً احتياطية مشفرة يومية لقاعدة البيانات.
- أضف حساباً منفصلاً لكل موظف من شاشة المستخدمين.

## النسخ الاحتياطي
لنسخ قاعدة البيانات احتياطياً:
`docker compose exec -T db pg_dump -U warehouse warehouse > backup.sql`

للاسترجاع:
`cat backup.sql | docker compose exec -T db psql -U warehouse warehouse`

## ملاحظات مهمة قبل التشغيل الفعلي
- هذه نسخة أولية (MVP) وليست بعدُ نظاماً مدققاً أمنياً أو جاهزاً للاستخدام الحساس دون مراجعة.
- يلزم نشر HTTPS، تغيير كلمات المرور الافتراضية، إعداد النسخ الاحتياطي واختبار الاسترجاع قبل إدخال بيانات حقيقية.
- إضافة/صرف متاحة للموظفين والمديرين. إضافة الأصناف وإدارة المستخدمين للمدير فقط.
- أسماء المخازن الافتراضية: المخزن الرئيسي، فرع 2، فرع 3؛ يمكن تغييرها في `WAREHOUSE_NAMES` قبل أول تشغيل.
- تعديل أسماء المخازن بعد بدء التشغيل يحتاج تحديثاً منظماً في قاعدة البيانات، وليس تغيير متغير البيئة فقط.
- لا تتضمن النسخة الحالية بعد: فواتير مشتريات/مبيعات، موردين وعملاء، باركود وطباعة، جرد تسوية، تصدير Excel، استعادة كلمة المرور، أو إدارة تفصيلية لصلاحيات كل فرع.
